# ADL Category Page Case

This project was developed using Angular for the Haratres Fit Internship Program interview process.

## Technologies

- Angular
- TypeScript
- HTML
- CSS

## Features
- Responsive adL-style category page
- Horizontal category slider (scrollable category buttons)
- Product image slider 
- Fully responsive design for different screen sizes
- Responsive navigation header
- Interactive dropdown menus (desktop mega menu)
- Product grid listing and view toggles 
- Dynamic color variant indicator (+X Colors)
- Add to cart button
- Favorite button
